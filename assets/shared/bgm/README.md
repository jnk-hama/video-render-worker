# BGM音源の出所（2026-08-28 取り込み）

## どこから来たか

https://github.com/uncle-sheepsky/duru-ai-cc0-bgm

**CC0 1.0 Universal**（パブリックドメイン提供）。商用利用可・帰属表示不要。
CC0なので**このリポジトリへ複製して良い**。

## なぜこの5曲だけか

元リポジトリには17曲あるが、READMEが2軸で分類している。
**両方を満たすものだけ**を取り込んだ。

| 軸 | 採用条件 | 除外したもの |
|---|---|---|
| 旋律 | `original`（作者の自作） | コロブチカ / グリーグ（19世紀のPD曲） |
| 作り | `[pure]`（100%コード合成） | `[+sfx]`（第三者のCC0効果音を重ねている） |

### コロブチカ系を外した理由
法的にはパブリックドメインで問題ない。ただし**テトリスの曲として広く
認知されているため、TikTok/YouTubeのContent IDが機械的に反応する恐れ**がある。
権利があっても収益化が止まれば損害は同じなので、避けた。

### `[+sfx]` を外した理由
第三者素材（BigSoundBank / Kenney / VSCO 2 CE / Freesound）のCC0判定に
依存する。連鎖のどれか1つが崩れると根拠が消える。
`[pure]` は外部サンプルを一切使わずコードで合成されており、
生成コードが元リポジトリの `src/` に実在する（＝主張に裏付けがある）。

## 320kbps → 96kbps へ再エンコードした理由

原本は320kbps。BGMは**音量0.2倍でナレーションの下に敷く**用途なので、
320kbpsは過剰。96kbpsで聴き分けはつかない。

  20MB → 5.9MB

GitHub Actions は描画のたびにリポジトリをチェックアウトするので、
容量はそのまま毎回の実行時間に効く。

## 使い方

job の `bgm` に指定する。

    "bgm": "random"                      → このフォルダから1本選ぶ（推奨）
    "bgm": "assets/bgm/duru-rondo.mp3"   → 曲を固定する
    "bgm": "https://.../music.mp3"       → 外部から取る

`random` にしておけば、曲を足したり入れ替えたりしてもGAS側は触らなくてよい。

## 注意

CC0は**アップロード主の一方的な宣言**である。今回は
「コードで合成した」という主張に生成コードという裏付けがあるため
かなり強い部類だが、個人の宣言であることに変わりはない。
